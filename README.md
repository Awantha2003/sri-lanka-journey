# 🇱🇰 Sri Lanka Journey 🧭


## 🌟 Features

- 🧠 **AI-based Smart Itinerary Generator**
- 🚗 **Auto-select hotels & vehicles** based on budget and group size
- 🌦️ **Live weather integration** per destination
- 🗺️ **Google Map view** with pins and route visualization
- 🧑‍💼 **Role-based login** (admin & customer)
- 💾 **Trip save & retrieve** for logged-in users
- 🔐 JWT Authentication (register, login, protected routes)



## 🧱Tech Stack

| Frontend            | Backend               | Database |
|---------------------|-----------------------|----------|
| React + TailwindCSS | Node.js + Express     | MongoDB  |
| React Router        | RESTful API           | Mongoose |
| Google Maps API     | JWT Auth Middleware   |          |
